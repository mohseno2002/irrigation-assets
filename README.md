# إدارات قطاع الري — الأصول والمنشآت المائية

تطبيق ويب عربى (PWA) لاستعراض وإدارة إدارات قطاع الري وهندساتها وترعها ومنشآتها المائية،
يعمل دون اتصال بالإنترنت، ويتزامن اختياريًا مع قاعدة Google Sheets.

**الرابط:** https://mohseno2002.github.io/irrigation-assets/

---

## بنية المستودع

المستودع مقصود أن يظل بهذا الحجم بالضبط — لا أدوات بناء، ولا حزم، ولا نسخ مكررة.

| الملف | الوصف |
|---|---|
| `index.html` | التطبيق كاملًا: الواجهة والأنماط ووحدة المزامنة ووحدات السجلات |
| `sw.js` | عامل الخدمة — كاش-أولاً للعمل دون اتصال |
| `manifest.webmanifest` | بيان التثبيت كتطبيق |
| `favicon.svg` · `pwa-icon.svg` | الأيقونات |
| `sector.json.gz` | السجل الأساسي مضغوطًا (بجوار `index.html` مباشرة) |
| `.nojekyll` | تعطيل معالجة Jekyll على GitHub Pages |

**لا يوجد** `package.json` ولا `node_modules` ولا مجلد `docs` ولا خطوة بناء.
ما تراه فى المستودع هو ما يعمل فى المتصفح حرفيًا.

## النشر

GitHub Pages من الفرع `main` والمجلد الجذر `/ (root)`.
كل الملفات فى الجذر بلا أى مجلدات فرعية — أى تعديل يُرفع مباشرة من واجهة GitHub
وينشر خلال دقيقة.

عند تعذر تحميل البيانات يعرض التطبيق **نص خطأ الخادم الحقيقى** ورقم HTTP والمسار
المطلوب داخل الواجهة، فلقطة الشاشة وحدها تكفى للتشخيص.

## القواعد الملزمة عند التعديل

1. **ممنوع علامات ‎`‎ (backticks) نهائيًا** — للتوافق مع التحرير من أندرويد/Termux.
   العدد الحالى فى `index.html` **صفر**، ويجب أن يظل صفرًا.
   التحقق: `python3 -c "print(open('index.html',encoding='utf-8').read().count(chr(96)))"`
2. **أى تعديل فى `index.html` يستوجب رفع `VERSION` فى `sw.js`** وتحديث رقم الإصدار
   فى تذييل الصفحة، وإلا ظلت النسخ المثبتة على البناء القديم.
3. **الأمانة قبل الإبهار**: لا تُضاف بيانات افتراضية أو إحداثيات مُقدّرة.
   كل رقم فى الواجهة محسوب من السجل المرفق.

## المزايا

- **بحث شامل موحّد** — بحث واحد يغطى المنشآت والترع والهندسات والإدارات **وكل الوحدات
  التخصصية الإحدى عشرة** (التراخيص، المخالفات، قرارات الإزالة، الأملاك، أورنيك الترع،
  السيارات والمعدات، الموارد البشرية، التغطيات، الترع المبطنة)، مع تطبيع عربى كامل
  (الألف والتاء المربوطة والألف المقصورة والتشكيل والأرقام العربية)، ودعم البحث بأكثر
  من كلمة، والبحث بكود السجل. الضغط على سجل وحدة يفتح بطاقته مباشرة. اختصار `Ctrl+K`.
- **جداول بلا سقف** — عرض تدريجى (٢٠٠ صف ثم «عرض المزيد» أو «عرض الكل»)، فلا تُقتطع
  سجلات أى إدارة مهما كبرت.
- **تقرير الإدارة الرسمى** — زر الطباعة يُخرج ورقة A4 بالهوية الرسمية للإدارة المركزية:
  الترويسة والشعار وصندوق الإشارة، ثم المؤشرات وتوزيع التصنيفات وموقف الهندسات
  وسجلات الوحدات، وكتلة الاعتماد وبيانات الاتصال.
- **لوحة مقارنة الإدارات** — كل الإدارات العامة جنبًا إلى جنب بمؤشرات الحجم واكتمال
  البيانات، بأعمدة قابلة للترتيب وتصدير CSV.
- **لوحة المناسيب والتصرفات** — باب مستقل داخل كل إدارة يفتح لوحتها التشغيلية
  (المناسيب والتصرفات ومتابعة الحجوز) **داخل التطبيق نفسه** عبر عارض مدمج بشريط علوى
  (رجوع · إعادة تحميل · فتح خارجى)، لا بتبويب جديد. الإطارات تُخزَّن فالعودة للوحة
  سبق فتحها فورية بلا إعادة تحميل. ومعه فهرس باللوحات المتاحة على مستوى القطاع.
  الروابط المنشورة فى `DEFAULT_BOARDS` داخل `index.html`؛ ويمكن ربط لوحة من الواجهة
  فتُحفظ على الجهاز لحين إضافتها للنسخة المنشورة.
- **بطاقة الإدارة التشغيلية** — الهيكل الإدارى، الكبارى والمنشآت، التغطيات، الأملاك،
  أورنيك الترع، التراخيص، محاضر المخالفات، قرارات الإزالة، الموارد البشرية،
  السيارات والمعدات، الترع المبطنة، وجودة البيانات.
- **معرّف ثابت لكل سجل** مشتق من هوية السجل نفسه، مع كود عرض قابل للنسخ.
- **مزامنة اختيارية** مع Google Apps Script: التعديلات تُحفظ محليًا فورًا وتُرسل تلقائيًا
  عند عودة الاتصال، مع سجل مراجعة وحلّ تعارضات.
- **عمل كامل دون اتصال** بعد الفتح الأول.

## البيانات

المصدر: «كبارى قطاع الرى — السجل الرقمى».
الملف يحوى 21,190 صفًا، يعرضها التطبيق كـ **21,188 سجل منشأة فريد** بعد دمج
سجلين متطابقى الهوية تمامًا (نفس الإدارة والهندسة والترعة والاسم والإحداثيات).

32 إدارة عامة · 206 هندسة · 4,590 ترعة ومجرى · 21,188 سجل منشأة،
منها 20,744 منشأة مرتبطة مكانيًا بإحداثيات (98٪).
